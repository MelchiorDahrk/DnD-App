# Questlog equipment renders

These 160×160 transparent WebPs are rendered from LDraw parts by the vendored
Bricktrait renderer (MIT, © 2026 Maxichance). They are not generated by an image
API. Part IDs, colours, and matched equipment names are in `equipment-icons.js`
at the repository root. Every equipment preset and default attack has a mapping;
`ACTION_ICONS` adds natural weapons and a general action token. Custom entries
use category artwork, with SVG fallbacks if an image cannot load. Related items
can share a representative accessory or small brick assembly.
Its `CURRENCY_ICONS` recipes use LDraw round 1×1 plate
6141 for the five money studs, with LDraw metallic and chrome colours.
Run `npm run build:portraits` after adding parts, or `npm run build:item-icons`
to re-render parts that are already packed.
