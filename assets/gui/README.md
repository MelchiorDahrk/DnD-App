# Questlog journal decorations

Two original, unmodified PNG assets from [Kenney Fantasy UI Borders 1.0](https://kenney.nl/assets/fantasy-ui-borders), created by Kenney on 2023-12-03. Licensed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The supplied license is preserved in `Kenney-LICENSE.txt`.

| Local file | Original archive path | Use |
| --- | --- | --- |
| `portrait-border.png` | `PNG/Default/Border/panel-border-013.png` | Nine-slice portrait frame, tinted with CSS |
| `journal-divider.png` | `PNG/Default/Divider/divider-000.png` | CSS mask tinted with the brass token |

The Fantasy UI Borders, UI Pack 2.0, and UI Pack Adventure 1.0 previews and assets were inspected. Only the consistent Fantasy Borders subset is shipped. Native CSS controls preserve keyboard behavior, accessibility, and flexible layout without redundant button images. The two PNGs total less than 1 KB. Their geometry is shared across appearances; no theme-specific image copies are needed.

Existing Questlog utility SVGs and all Bricktrait, LDraw, LEGO equipment, portraits, scenery, and effects remain in their original systems. No new weapon, item, or armor icon library is introduced. System fonts require no extra downloads or font licensing. Everything required by the redesigned shell is bundled and precached locally.
