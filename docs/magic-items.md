# Magic items

The catalog covers all **503 distinct 2024 wiki item pages** and all **830 published 2014 wiki item pages**. **2024 stats and descriptions always take precedence** for a shared item or a reviewed renamed equivalent. The earlier index contributes **502 earlier-only items**; its other **328 entries** resolve to the current revisions. There are no duplicate older versions of shared items.

The result is **1,007 distinct magic items**, plus 18 convenient potency presets: Greater/Superior/Supreme Healing and +1/+2/+3 armor, weapons, shields, ammunition, and Wands of the War Mage. This gives **1,023 magic-item presets** and **1,357 total inventory presets**, with ordinary equipment and Potion of Healing counted once.

Every item includes its individual wiki link, listed source, rules edition, item type, rarity choices, attunement requirements, price where listed, effects, relevant stat tables, and a representative bundled LEGO icon. Supplemental and wiki-specific items keep their listed source. Complicated artifacts have concise reference summaries and links to their complete rules. Variant tables retain their individual stats even when they share an inventory preset.

Use **Add item → Equipment & magic items** to search by name, effect, source, edition, or table value. Combine equipment type, rarity, attunement, and rules-version filters. **Compendium → Magic items** also supports search, rarity and rules-version filters, artwork, and scrollable stat tables. The 2014 filter shows earlier-only items; shared items appear under 2024. Selecting a preset fills editable inventory fields and its LEGO icon. The catalog and icons work offline after caching.

Examples of revision precedence: Bag of Holding uses its 2024 **5 lb.** weight and rules; the 2014 15 lb. version is not offered. Drinking or administering any potion uses the 2024 Bonus Action; oils keep their specified application time. See the [2024 magic-item category rules](https://www.dndbeyond.com/sources/dnd/br-2024/magic-items). Wraps of Unarmed Prowess resolve to Wraps of Unarmed Power, Scroll of Tarrasque Summoning to Scroll of Titan Summoning, and Arrow of Slaying to Ammunition of Slaying. Distinct items stay separate: the common Eberron Feather Token prevents fall damage, while Quaal’s Feather Token has its own magical forms.

Prices preserve wiki conventions: **B** means the base equipment price; **Varies** means variant-dependent pricing. The 2014 index does not list prices, so earlier-only items say **Unlisted (2014 wiki)**. Every physical carried item has a weight. Listed weights override base gear: Gurt’s Greataxe weighs 325 lb., Staff of Defense 3 lb., and the colored Alchemy Jugs 12 lb. Items without specified weights use labeled, editable estimates based on their physical form. Variable weapon and armor families name their default base; adjust it for the chosen variant. Magical ammunition defaults to one arrow (0.05 lb.) per piece, while ordinary ammunition remains bundled. Portable Hole retains its listed negligible weight; the Sphere of Annihilation is a spatial void, and Ythryn Mythallar is an uncarried installation. Potions and base wands/staves/rods use labeled standard weights when no specific weight is provided. Earlier-only magical effects retain their sources, while common base weapons, armor, and potion activation follow 2024 rules. Item-specific magical overrides still apply. Saved inventory weights and customized notes are preserved.

AC updates automatically from equipped armor, shields, and supported defensive magic items, including Rings/Cloaks of Protection, Bracers of Defense, and defensive staves. Mark required attunement in the item editor; its AC bonus applies only while equipped and attuned. Choose the actual base armor for variable magic armor, or enter an AC bonus for custom items and conditional effects when active. Duplicate copies do not stack. Other effects on ability scores, movement, charges, and spell resources remain explicit player edits; use Features & resources for charge counters. Consumable potions and scrolls reduce quantity when used. Only ordinary Potion of Healing automatically rolls healing; stronger tiers state their formulas and require applying healing separately. Existing saved inventory and customized notes are preserved.

## Data and regeneration

`magic-item-data.js` contains the current catalog. `legacy-magic-item-data.js` contains only the earlier-only additions plus the complete revision mapping. Both are committed, so ordinary builds need no wiki connection. `magic-item-icon-names.js` is a small generated artwork alias list; importing the LDraw renderer does not pull in the rules catalogs.

`scripts/data/magic-item-summaries.json` and `scripts/data/legacy-magic-item-summaries.json` contain original concise mechanics summaries. Current SRD entries use the openly licensed 2024 rules via [5e-bits/5e-database](https://github.com/5e-bits/5e-database/tree/main/src/2024/en); any un-revised SRD references retain their 2014 attribution. The earlier source index is recorded in `scripts/data/legacy-magic-item-index.json`. The Infernal Machine’s 100 effects use original compact table summaries so the complete preset fits existing backup limits.

Run `npm run build:magic-items` with `.tmp/rest-wiki/`, `.tmp/legacy-magic/`, and `.tmp/rules/` research caches present. Add `-- --download` to refresh public sources. The command rebuilds 2024 first, then resolves the 2014 index against those current items. `scripts/lib/magic-item-weights.mjs` supplies shared listed weights, base choices, and reviewed physical-form estimates for both importers; new unrecognized forms fail generation instead of silently receiving zero. New non-SRD pages require a reviewed original summary. Importers validate metadata, missing summaries, and source coverage, and isolate page content from advertising, navigation, scripts, and tags. The 2014 source legend is treated as attribution, not pricing.

`MAGIC_ITEM_AUDIT` records all current source paths. `LEGACY_MAGIC_ITEM_AUDIT` records all 830 earlier source paths, the 502 additions, and each of the 328 current-revision targets. Renamed equivalents are reviewed aliases, not fuzzy name matches. Category and homebrew index links do not count as item pages.

## LEGO artwork

All **266 icons** are transparent 160×160 WebPs rendered from real LDraw parts. This expansion adds **22 renders**, improving both editions: amulets, belts, brooms, goggles, wings, bats, hourglasses, figurines, crystal balls, cauldrons, elemental bowls, pearls, tattoo needles, flying carpets, crystal staves, flame/frost/sun blades, serpents, annihilation spheres, winged boots, and spider staves. Related items share representative artwork; the editable library also permits manual choices.

`equipment-icons.js` records part IDs, colors, assemblies, and viewing angles. `scripts/lib/magic-item-art.mjs` supplies reviewed mappings for both importers. Run `npm run build:item-icons` to render packed parts, or `npm run build:portraits` to pack new geometry and preserve the LDraw attribution pipeline. See [equipment artwork credits](../assets/equipment/README.md).

Validation: `npm test`, `npm run check`, `npm run test:magic-items`, `npm run test:item-icons`, `npm run test:sheet`, and `npm run build`. Coverage tests account for every source page, enforce revision precedence, check actual local artwork and stats, and round-trip all presets through version 2 backups. Browser checks cover filters, preserved edits, selecting icons, tables, mobile layouts, saving/reloading, and offline use under a hosted subpath.
